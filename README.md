# Portfolio Management personal project

## Overview

This repository contains the main materials related to my portfolio management project. The core ideas, methodology, and results are documented across separate files, so this README only gives a brief map of the repository.

## Repository Content

- `project_pitch_slide.pdf`: initial project pitch presented in a few slides before any coding or integration work.
- `Linkedin posts/`: archive of the material that was published on LinkedIn.
- `V1_appendix_risk.ipynb`: risk analysis of individual assets and cross-asset relationships, used to identify and publish risk profiles.
- `V1_condensed`: condensed version of the main model, including macro framework, allocation choices, portfolio construction, and historical backtest.
- `V1_documentation.pdf`: documentation of the methods and key findings of version 1.
